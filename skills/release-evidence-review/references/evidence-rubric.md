# Release evidence rubric

| Handoff claim | Supplied evidence | Review |
| --- | --- | --- |
| The preview builds | A passing build log for the stated revision | Supported for that preview build |
| The change reached production | A preview screenshot and a successful CI check | Inconclusive. Request the deployment ID and a production observation. |
| The contact form delivers mail | A screenshot of the success message | Inconclusive. Request a permitted receipt or inbox confirmation for the same test. |
| The header displays the new link on mobile | A production screenshot from the stated release at a phone viewport | Supported for that viewport |

Write one line per claim with its status, exact evidence and any missing check. A release identifier that differs from the handoff belongs in the evidence column so the owner can reconcile it.
